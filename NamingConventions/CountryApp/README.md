# CountryApp — Adjacent Countries Console App

## What is this
A simple C# console application that takes a 2-letter country code (e.g. IN, US, NZ) and displays the full names of its neighbouring (adjacent) countries.

## How to run

1. Make sure you have .NET SDK installed.  
   Run in terminal:  
    ```dotnet --version```

2. Open a terminal at the project folder (where `CountryApp.csproj` is located).  
Example:
    ```cd C:\Learn-Code\LearnAndCode\NamingConventions\CountryApp```

3. Run the application:
```dotnet run```
